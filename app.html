Demo limitation: this form saves a note in this browser only. It does not send the note to Sciar, Halloran’s, or a manager, so Sciar cannot use it to improve the product. The case pack provides no submission service or named recipient. Anyone with access to this browser profile or device may be able to read the saved note.

Only enter what is needed to describe the issue. Avoid names, contact details, or other identifying or sensitive information unless it is essential to explain the concern. The note is saved only when you choose Save; it is not uploaded by this page.

Saved entries remain in this browser’s local storage until deleted here or browser data is cleared. This is a demonstration, not a monitored complaint or product-feedback channel.

Product feedback: no live route to Sciar is configured in this project. A real product should offer a separate, clearly explained optional feedback route, with a named recipient, purpose, access limits, retention period, and user-facing privacy information.
